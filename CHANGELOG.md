## 0.1.0 — 2026-10-12

First structured release, refactored from the 2026-10 research scripts.

* Package layout `src/industrial_tsad/{configs, core/models, core/fusion, datasets, evaluators, runners, registry, utils, presets}`,
  entry points in `local/`, unit tests in `tests/`, documentation in `docs/`.
* Detectors behind one interface and a registry: PaAno (+ final configuration), MSCAD (re-implementation, mode tokens),
  AxonAD (+ mode-token adapters), CATCH, KAN-AD, TimesNet.
* Strict pydantic configs and YAML presets; benchmark runner with claim files (several workers per run), saved scores
  and score parts; paired bootstrap statistics, dataset rule, claim rule with Bonferroni looks; regime gate and score
  fusion; pre-registration records with code hashes.
* Reproduction checked against the saved research runs: MSCAD and AxonAD bit-identical, PaAno within GPU nondeterminism
  (VUS-PR equal). MSCAD restores the global TF32 flags after each call (they used to leak into later models).
* Published per-series results: `published_table()` merges the TSB-AD table with leaderboard CSVs of both contributor
  formats, from the TSB-AD clone and from `<TSB-AD data>/leaderboard_results/` (AxonAD, StreamVAE).
* README figures: animated regime-gate example and detector tour on TSB-AD-M series, results chart, gate figure,
  architecture and protocol diagrams (Archify sources and interactive HTML in `docs/diagrams/`), regenerated by
  `scripts/make_readme_figures.py` and `scripts/make_readme_animation.py`.
* Released under the MIT License; `LICENSE` and `THIRD_PARTY_NOTICES.md` are shipped as license files of the package
  (SPDX metadata, setuptools 77 or newer).
